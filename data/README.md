# Récupération des données

Jeu : **SEED-VIG** (sous-ensemble de SEED, BCMI, Shanghai Jiao Tong University).
Accès fourni par l'enseignant ; redistribution interdite hors du cours.

1. Télécharger l'archive transmise par l'enseignant (environ 2 Go).
2. La décompresser **hors du dépôt Git** (par exemple `C:/donnees/SEED-VIG`).
3. Mettre ce chemin dans `configs/config.json`, champ `data_dir`.
4. Vérifier avec : `python src/explore.py --data-dir "C:/donnees/SEED-VIG"`.
